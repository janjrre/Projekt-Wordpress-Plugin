# Projekt-Wordpress-Plugin

Wordpress Plugin für Verwaltungsportal usw.

## Architektur und Spezifikation

Die verbindlichen Architektur- und Implementierungsdokumente liegen unter [docs/specification](docs/specification/README.md).

Die Entwicklung beginnt gemäß Specification Freeze ausschließlich mit Milestone 0 und Milestone 1.

## Projektarbeit und nachvollziehbare Übergaben

Vor jeder Arbeit an UOP Core gelten die [verbindlichen Agenten-/Entwicklungsregeln](AGENTS.md). Arbeitsaufträge, dokumentierte Entscheidungskriterien, tatsächliche Änderungen, Prüfungen und Blocker gehören in das [fortlaufende Arbeitsprotokoll des Hauptbranches](https://github.com/janjrre/Projekt-Wordpress-Plugin/blob/main/docs/operations/ASSISTANT_WORK_LOG.md). Die OrgaVela-Hosting-Sperre und die sichere Korrektur sind in [Issue #12](https://github.com/janjrre/Projekt-Wordpress-Plugin/issues/12) und der [Korrekturanleitung](https://github.com/janjrre/Projekt-Wordpress-Plugin/blob/main/docs/operations/orgavela-utf8mb4-recovery.md) beschrieben.
